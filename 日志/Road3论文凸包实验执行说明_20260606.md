## no-preview / preview 切换

Simulink 接口不变，只改 CarSim VS Command 中 `W1_* / W2_*` 的定义。

preview 模式使用：

```text
Carsim参数集/VSCommand/Road3_preview_exports_2020.txt
```

no-preview 模式使用：

```text
Carsim参数集/VSCommand/Road3_no_preview_exports_2020.txt
```

preview 核心定义：

```text
EQ_OUT W1_L1 = road_z(X_L1 + Vxz_Fwd * 0.01, Y_L1)
EQ_OUT W1_R1 = road_z(X_R1 + Vxz_Fwd * 0.01, Y_R1)
EQ_OUT W1_L2 = road_z(X_L2 + Vxz_Fwd * 0.01, Y_L2)
EQ_OUT W1_R2 = road_z(X_R2 + Vxz_Fwd * 0.01, Y_R2)

EQ_OUT W2_L1 = road_z(X_L1 + Vxz_Fwd * 0.02, Y_L1)
EQ_OUT W2_R1 = road_z(X_R1 + Vxz_Fwd * 0.02, Y_R1)
EQ_OUT W2_L2 = road_z(X_L2 + Vxz_Fwd * 0.02, Y_L2)
EQ_OUT W2_R2 = road_z(X_R2 + Vxz_Fwd * 0.02, Y_R2)
```

no-preview 核心定义：

```text
EQ_OUT W1_L1 = road_z(X_L1, Y_L1)
EQ_OUT W1_R1 = road_z(X_R1, Y_R1)
EQ_OUT W1_L2 = road_z(X_L2, Y_L2)
EQ_OUT W1_R2 = road_z(X_R2, Y_R2)

EQ_OUT W2_L1 = road_z(X_L1, Y_L1)
EQ_OUT W2_R1 = road_z(X_R1, Y_R1)
EQ_OUT W2_L2 = road_z(X_L2, Y_L2)
EQ_OUT W2_R2 = road_z(X_R2, Y_R2)
```

注意：`X_*` / `Y_*` 只能作为说明文档里的通配占位符，不能复制到 CarSim VS Command。CarSim 2020 会把 `X_` 识别成未定义符号并报错。实际运行必须使用上面展开后的 `X_L1/Y_L1`、`X_R1/Y_R1`、`X_L2/Y_L2`、`X_R2/Y_R2`。

## 三组对比命令

T1 full：

```matlab
addpath('src_2020');
AnalyzeRoad3BumpExperiment_2020({ ...
    'Output/Road-3/T1_passive/your_result.csv', ...
    'Output/Road-3/T1_no_preview/your_result.csv', ...
    'Output/Road-3/T1_preview/your_result.csv' ...
}, 'Output/Road-3/T1_road3_bump_compare.md');
```

T2 full：

```matlab
addpath('src_2020');
AnalyzeRoad3BumpExperiment_2020({ ...
    'Output/Road-3/T2_passive/your_result.csv', ...
    'Output/Road-3/T2_no_preview/your_result.csv', ...
    'Output/Road-3/T2_preview/your_result.csv' ...
}, 'Output/Road-3/T2_road3_bump_compare.md');
```

Road-3 专用报告会输出：

- `Az_SM*9.81` 的 event RMS、`0-4 Hz` RMS、`0-15 Hz` RMS。
- `AA_P`、`AA_R` 的 event RMS、`0-4 Hz` RMS、`0-15 Hz` RMS。
- `Zcg_SM` 相对初值的 heave 位移峰值。
- `Pitch/Roll` 峰值。
- 四角 `FsExt_*` 峰值、RMS、饱和比例。
- 前后轴左右外力差。
- `Jnc/JncR` 峰值。
- 轮转增量。

full 验收重点：

- 配置限幅饱和比例 `< 5%`。
- 后轴左右外力差峰值 `< 1000 N`。
- preview 组相对 no-preview 在 `Az_SM` 或 `AA_P` RMS 上不恶化。
- 若趋势相反，先查 `W1/W2` 对齐和力饱和，不先改 MPC 权重。

## 出错处理

- 如果 CarSim `Run the Math` 失败，先检查 Results 文件夹，不先动 Simulink。
- 如果 VS Visualizer 崩溃，先检查 CarSim 数据集标题、描述、Road ID 是否含中文或特殊字符。
- 如果 pilot 已经出现持续饱和或强振荡，停止进入 full 工况，回退到 Road-2B 设置核对。
