# Road3 nonlinear 去除 Simulink Gain 后 T2 50 mm 结果复核

## 背景

2026-06-11 确认 `IMP_FS` 符号后，去掉 `per_corner_mpc` 输出到 CarSim `IMP_FS` 之间的 `Gain=-1`。该修改使 nonlinear active 的响应明显改善，说明此前主动控制存在系统级反号风险。

## 已检查报告

- 500 N: `Output/nonlinear/test/50mm/report_opposite.md`
- 400 N: `Output/nonlinear/test/50mm/ROAD3_NONLINEAR_FRONT400_GATE_UV_POS/report.md`

## 关键发现

`report_opposite.md` 的 passive 对照路径为：

```text
E:\Scientific_Research\claude\Output\nonlinear\test\passive.csv
```

该 passive 的 road peak 为 `0.103758 m`，而 active 的 road peak 为 `0.0499285 m`。因此这份报告把 50 mm active 与约 100 mm passive 进行了比较，不能用于证明 500 N active 全面超过 T2 50 mm passive。

400 N 报告中的 active/passive road peak 均为 `0.0499285 m`，属于同一路面可比结果。

## 当前结论

1. 去掉 `Gain=-1` 是正确方向，说明此前 active 性能受符号错误严重限制。
2. `report_opposite.md` 的被动对照路面峰值不一致，不能作为最终性能结论。
3. 在当前可比报告里，`ROAD3_NONLINEAR_FRONT400_GATE_UV_POS` 比 500 N active 更保守，且在 `Az event/0-15 RMS` 上已能小幅优于同路面 Passive，但姿态和低频指标仍未全面超过。
4. 下一步应先重新生成 500 N 对同一份 50 mm passive 的 corrected report，再做 450/500/550 N 的小范围扫描；不要基于错误 passive 对照直接冻结 500 N。
