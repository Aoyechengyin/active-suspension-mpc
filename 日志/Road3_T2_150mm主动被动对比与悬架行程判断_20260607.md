# Road3 T2 150mm 主动/被动对比与悬架行程判断

## 数据

- Passive: `Output/Road-3/paper_road/passive/2026-06-07_23.17.21.csv`
- Active: `Output/Road-3/paper_road/T2_150mm_preview/2026-06-07_23.23.06.csv`
- 路面峰值: `0.149784 m`
- 事件窗口: `6.711 s` 到 `10.613 s`
- Active 设置按当前论文工况最佳折中组合理解: `ROAD3_Q_COMFORT_C + ROAD3_PAPER_ACTIVE_BEST / UV_POS`

## 主动是否大部分优于被动

结论: 否。150 mm full 工况下，主动组在主要舒适性指标上没有超过被动，整体是轻微变差。

| 指标 | Passive | Active | Active - Passive | 判断 |
|---|---:|---:|---:|---|
| Az event RMS (m/s^2) | 3.39741 | 3.43321 | +0.03580 | 变差 |
| Az 0-4 Hz RMS (m/s^2) | 2.15439 | 2.21901 | +0.06463 | 变差 |
| Az 0-15 Hz RMS (m/s^2) | 3.12412 | 3.14948 | +0.02536 | 变差 |
| AA_P 0-15 RMS (rad/s^2) | 2.92000 | 2.95833 | +0.03833 | 变差 |
| Zcg_SM heave peak abs (m) | 0.126351 | 0.128449 | +0.00210 | 变差 |
| Pitch peak abs (deg) | 5.20733 | 5.27912 | +0.07179 | 变差 |
| front Jnc min | -85.158 | -85.225 | -0.068 | 轻微变差 |
| rear Jnc min | -31.021 | -39.542 | -8.520 | 明显变差 |

唯一可以说略有改善的是 `Zcg_SM` 在事件窗口内的 min-max range:

| 指标 | Passive | Active | Active - Passive |
|---|---:|---:|---:|
| Zcg event range (m) | 0.185620 | 0.181655 | -0.003965 |

但这个改善没有转化为 heave peak、Az RMS 或 pitch 的优势，因此不能作为论文结论中的主优势。

## 跳起/离地诊断

150 mm 工况下，被动和主动都已经进入强非线性区。

| 指标 | Passive | Active | 判断 |
|---|---:|---:|---|
| Vz_SM min/max (m/s) | -2.839 / 2.997 | -2.896 / 3.040 | Active 略大 |
| Az min/max (m/s^2) | -32.220 / 38.625 | -32.550 / 39.268 | Active 略大 |
| Fz min all wheels (N) | 0.000 | 0.000 | 两者均离地/卸载 |
| Fz <= 100 N fraction | 7.4494% | 7.4878% | 两者接近，Active 略差 |
| Fz <= 0 N fraction | 7.4366% | 7.4430% | 两者接近，Active 略差 |

这说明“车身直接跳起来”不是主动控制单独造成的；Passive 同样发生轮胎垂向力降到 `0 N` 的离地/卸载现象。当前 150 mm full 工况已经超出该车辆模型在现有悬架行程/止块参数下的合理复现范围。

## 止块与悬架行程

前悬是主要问题。事件窗口内的前悬 jounce/rebound stop force 已达到几十 kN，后悬止块力仍为 0。

| 指标 | Passive | Active | 判断 |
|---|---:|---:|---|
| FJSt_L1/R1 max (N) | 43056 / 43317 | 44396 / 44569 | Active 更大 |
| FRSt_L1/R1 min (N) | -32868 / -32826 | -33283 / -33278 | Active 更大 |
| FJSt_L2/R2 max (N) | 0 / 0 | 0 / 0 | 后悬未触发 jounce stop force |
| FRSt_L2/R2 min (N) | 0 / 0 | 0 / 0 | 后悬未触发 rebound stop force |
| CmpJSt front min/max | -52.287 / 73.332 | -52.328 / 73.457 | 前悬已越过当前止块区 |
| CmpJSt rear min/max | -30.946 / 98.810 | -39.451 / 98.843 | 后悬接近但未触发止块力 |

结合 CarSim 截图中的前悬行程设定 `+70 mm / -50 mm`，150 mm speed bump 让前悬超过 jounce/rebound stop 区间。主动控制没有缓解这个问题，反而使前悬止块力和后悬回弹位移略有恶化。

## 决策

1. 当前主动组合不能声明在 T2 full `150 mm / 2.5 m / 50 km/h` 上大部分优于 Passive。
2. 继续只调 MPC 或输出层意义不大，因为 Passive 本身也离地，且前悬止块力已经主导响应。
3. 若论文必须复现 `150 mm` 工况，应进入 CarSim 车辆模型层修改，优先复制车辆/悬架 stop 数据集后建立 `Road3_paper_longtravel` 版本，而不是覆盖现有基准车辆。
4. 修改行程后必须重新跑 Passive、no-preview、preview，因为物理基线改变后旧结果不可直接对比。
5. 如果不修改车辆模型，则 T2 full 应标注为当前 E-Class SUV 悬架行程约束下的极限工况，不适合作为主动控制效果主结论。

## 建议下一步

- 保留当前车辆参数作为 `Road3_baseline_vehicle`。
- 复制 CarSim suspension jounce/rebound stop 数据集，建立 ASCII 命名的新车辆/悬架版本。
- 优先扩大前悬 jounce/rebound stop 区间，并降低止块突变刚度，避免 `+70/-50 mm` 附近出现几十 kN 的硬冲击。
- 用修改后的车辆重新跑:
  - T2 full Passive
  - T2 full Active best
  - 必要时再跑 no-preview
- 只有在修改后 `Fz <= 100 N` 比例显著下降、前悬 stop force 不再达到几十 kN 时，才继续讨论主动控制是否优于被动。
