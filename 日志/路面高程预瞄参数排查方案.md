# 路面高程预瞄参数排查方案

> 日期: 2026-05-29
> 依据: 仿真日志 PDF (2026.5.29 21:42)
> 问题: W1/W2 预瞄信号与当前路面高程没有时间关系，导致控制器失效

## 仿真日志发现的问题汇总

1. 左前轮执行器力在 5 秒后迅速达到最大值 9000N 不动；其他轮执行器力直接从 0 跳到 9000N
2. CarSim 输出端车身状态全部异常为 0，相当于没有输出
3. 四个轮当前路面高程均有输出，但同一侧前后轮当前路面高程出现偏移
4. **预瞄点 1、2 的路面高程与当前路面高程没有时间关系**，与当初设置的 CarSim 参数配置不符
5. 初步结论：Carsim 路面高程输出设置有误 或 自定义路面高程参数的计算公式有问题

## 当前配置分析

```
EQ_OUT W1_L1 = road_z(X_L1 + 0.138889, Y_L1);   % 固定距离 0.138889m
EQ_OUT W2_L1 = road_z(X_L1 + 0.277778, Y_L1);   % 固定距离 0.277778m
```

### 问题 1: 固定距离 ≠ 速度相关预瞄

0.138889m 对应的预瞄时间 **仅在 50km/h 时才正确**：

| 车速 (km/h) | Vxz (m/s) | 0.138889m 对应时间 | 期望 10ms 对应距离 | 误差 |
|-------------|-----------|-------------------|-------------------|------|
| 30          | 8.33      | 16.7 ms           | 0.083 m           | +67% |
| 50          | 13.89     | 10.0 ms ✅        | 0.139 m           | 0%   |
| 80          | 22.22     | 6.3 ms            | 0.222 m           | -37% |
| 100         | 27.78     | 5.0 ms            | 0.278 m           | -50% |

**任何非 50km/h 的车速下，预瞄距离都是错的。**

### 问题 2: 无 Yaw 修正

当前配置只做 X 方向偏移，车辆转弯时预瞄点不在行驶方向上。

### 问题 3: DEFINE_OUTPUT 初始值 = 0

仿真首步 W1/W2 输出为 0，可能造成状态估计器突变。

## 排查步骤

### 第 1 步: 验证 W1/W2 与 Zgnd 的时间关系

在 Simulink 中添加 3 个 Scope：
```
Zgnd_L1 (输出端口 11)  ─┐
W1_L1   (输出端口 17)  ─┼→ Scope1
W2_L1   (输出端口 21)  ─┘
```

预期观察（凸块工况）：
- Zgnd_L1 先出现凸块波形
- W1_L1 约提前 Δt1 出现
- W2_L1 约提前 Δt2 出现（Δt2 > Δt1）
- 三者波形形状相似，仅时间平移

**如果 W1/W2 与 Zgnd_L1 几乎同步 → 预瞄失效**

### 第 2 步: 检查 CarSim 路面文件是否足够长

如果路面文件总长度 < 预瞄偏移距离，`road_z()` 会返回边界值或 0，导致 W1/W2 与 Zgnd_L1 无关。

### 第 3 步: 验证 EQ_OUT 语法是否被 CarSim 执行

在 CarSim 中：
1. 运行仿真后查看 Export 通道日志
2. 确认 W1_L1~W2_R2 的数值在行驶中有变化
3. 如果始终为 0 → EQ_OUT 未生效

### 第 4 步: 修复预瞄参数公式

**修复方案: 恢复速度相关配置**

将 `DEFINE_OUTPUT` 改为使用 `Vxz_Fwd` 的动态公式：

```
DEFINE_OUTPUT W1_L1 = road_z(X_L1 + Vxz_Fwd * 0.01, Y_L1);
DEFINE_OUTPUT W2_L1 = road_z(X_L1 + Vxz_Fwd * 0.02, Y_L1);
```

或如果 CarSim 版本不支持在 `DEFINE_OUTPUT` 中引用变量：

```
EQ_OUT W1_L1 = road_z(X_L1 + Vxz_Fwd * 0.01, Y_L1);
EQ_OUT W2_L1 = road_z(X_L1 + Vxz_Fwd * 0.02, Y_L1);
```

**如果 Vxz_Fwd 不可用**，用 CarSim 的 `Vx_CG` 或 `V` 替代。

### 第 5 步: 修复后验证

1. 固定车速 50km/h → W1 应提前约 10ms，W2 提前约 20ms
2. 变速工况 → 预瞄距离应随车速变化
3. 被动模式 (u_cmd=0) 应能跑通全程无崩溃
4. MPC 模式控制力不应长期锁在 ±9000N

## 预期修复效果

| 修复前 | 修复后 |
|--------|--------|
| W1/W2 与 Zgnd 同步，无预瞄效果 | W1 提前 ~10ms，W2 提前 ~20ms |
| 控制器因错误预瞄输出饱和力 | 控制器提前补偿路面激励 |
| 车轮跳震 + 偏移 | 跳震消除，偏移收敛 |
| 执行器力锁在 9000N | 执行器力在合理范围内波动 |

## 注意事项

- 修改 CarSim 参数后需重新 "Send to Simulink" 生成新的 S-Function
- 修改后需重新运行 Step3 重建离线数据（预瞄距离变化会影响状态空间边界）
