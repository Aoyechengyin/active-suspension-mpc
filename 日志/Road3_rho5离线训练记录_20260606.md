## 当前激活状态

本次只完成离线训练和数据归档，尚未把新 `.mat` 激活到 `src_2020` 根目录。

原因：当前 Road-3 结果仍需要保留 B3 基准可复现性。激活 profile 会复制新 `.mat` 到根目录，虽然会自动备份旧数据，但建议在准备跑下一次 T2 pilot 前再执行。

激活命令：

```matlab
addpath('src_2020');
addpath('src_2020/road3_rho5_offline');

profile_dir = fullfile('src_2020', 'road3_rho5_offline', 'data', 'ROAD3_SOFT_F1E5_R1E4');
backup_dir = ActivateRoad3Rho5Profile_2020(profile_dir);

clear per_corner_mpc_L1_2020 per_corner_mpc_R1_2020 ...
      per_corner_mpc_L2_2020 per_corner_mpc_R2_2020 ...
      per_corner_mpc_state_step_2020
```

恢复命令：

```matlab
RestoreRoad3Rho5Backup_2020(backup_dir);

clear per_corner_mpc_L1_2020 per_corner_mpc_R1_2020 ...
      per_corner_mpc_L2_2020 per_corner_mpc_R2_2020 ...
      per_corner_mpc_state_step_2020
```

## 下一步建议

1. 激活 `ROAD3_SOFT_F1E5_R1E4`。
2. 跑 `T2 50 mm pilot preview`。
3. 对比旧 preview 的以下指标：
   - `FsExt_*` 全程和 event 饱和比例
   - `Jnc_L1/R1` 最小值
   - `Az_SM` event RMS 和 0-15 Hz RMS
   - `AA_P` event RMS 和峰值
4. 如果饱和仍明显超过 `<1%`，再训练 `ROAD3_SOFT_F1E4_R3E4` 或引入 Road-3 专用输出缩放/限幅模式。
