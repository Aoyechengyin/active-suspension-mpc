# 仿真模型有效性验证报告

日期：2026-06-11  
对象：CarSim/Simulink 主动悬架 eMPC 模型、Road-3 路面输入、`src_2020` 与 `src_nonlinear` 离线控制律数据集

## 1. 总体结论

当前模型已经具备继续做 Road-3 T2 pilot 控制器对比和后续 rear-only 调试的基础有效性：路面 CSV、预瞄提前量、前后轴路面延迟、基础平路稳定性、Gurobi 离线求解、regionless 控制律验证、控制律资产激活/回退流程均有记录或脚本支撑。

但还不能把模型写成“完全验证通过”。目前仍有 3 类关键缺口：

1. **通道顺序和控制力符号只有间接验证**：已有 Simulink 接线修复、反向符号对比、UV_POS/UV_NEG 对比，但缺少“四角单独力脉冲注入”这种最直接的端到端验证。
2. **静态平衡只验证了轮胎法向载荷闭合趋势**：T2 50 mm passive 平路窗口四轮 `Fz` 之和约 `18758 N`，对应等效总质量约 `1912 kg`；但这不是严格的“簧上质量”验证，仍需导出 CarSim 质量参数或簧上/非簧载荷分解。
3. **非线性控制律路径曾出现过错误**：2026-06-11 用户执行 `which per_corner_mpc_L1_2020` 时显示仍来自 `src_2020`，因此 `Output/nonlinear/T2-50mm-preview/2026-06-11_15.07.05.csv` 不能作为 nonlinear preview 有效结果。已通过 `src_nonlinear/use_nonlinear_suspension_path_2020.m` 建立路径检查流程，后续仿真必须先确认 shadow wrapper 生效。

## 3. 关键验证细节

### 3.1 路面输入、预瞄与前后轴延迟

Road-3 T2 50 mm pilot 路面文件为：

- `Carsim参数集/3D路况文件/Road3_T2_long_50mm_pilot_210m_0p05m.csv`

该文件在 `100.00-102.50 m` 之间为 half-sine 凸包，峰值在 `101.25 m`，高度 `0.050 m`。在 2026-06-11 的 passive 结果中复算得到：

| 信号 | 峰值时间 | 峰值 |
|---|---:|---:|
| `Zgnd_L1/R1` | `7.301 s` | `0.049928 m` |
| `Zgnd_L2/R2` | `7.514 s` | `0.049928 m` |
| `W1_L1/R1` | `7.291 s` | `0.050000 m` |
| `W2_L1/R1` | `7.281 s` | `0.050000 m` |

结论：

- W1/W2 的峰值时刻分别提前 `10 ms` 和 `20 ms`，符合 Road-3 设计。
- 后轴路面输入相对前轴滞后 `0.213 s`。按 50 km/h 约 `13.89 m/s` 估算，反推轴距约 `2.96 m`，物理量级合理。
- 该结论与 `Output/Road-3/T2_passive/road_acceptance_report.md` 中 PASS 的预瞄表一致。

### 3.2 接口顺序与控制力符号

已有证据支持“接口大体可用”，但 2026-06-11 的力脉冲试验暴露出一个必须单独处理的符号层级问题：**离线控制律中的 `u` 与 CarSim `IMP_FS` 本体方向一致，但 Simulink 输出端若接了 `Gain=-1`，在线实际作动力会与离线模型相反。**

- `src_2020/fix_simulink_io_2020.m` 用于修复 Subsystem 输出与根 Mux 的连线，目标通道顺序为 `[L1, L2, R1, R2]`。
- `Output/CaseB4/baseline_manifest_20260606.md` 记录了基线 Mux order。
- `Output/CaseB2-rev/flat_pose_report_compare_B2_rev.md` 与后续日志说明，后轴反向符号方案导致振荡加重，因此 rear 方向不能简单取反。
- `Output/nonlinear/T2_50mm_front500_gate_compare_20260611.md` 显示 `UV_POS` 相对 `UV_NEG/ENG` 更好，说明当前基于车身速度的耗能方向符号判断更符合系统响应。
- 2026-06-11 力脉冲试验：四个车轮 `IMP_FS` 同时给恒定正值，车辆通过单凸包时，起初四角 `Jnc` 从零下降到稳定负值，通过凸包时 `Jnc` 突增并振荡，之后回到原负值附近。该现象说明 CarSim 中正 `IMP_FS` 对簧上质量等效为向下作用力；在当前 `Jnc` 记号下，正力的静态效果是使 `Jnc/susp_defl` 变负。
- 离线模型与该结论一致：`src_nonlinear/TrainNonlinearSuspensionOffline_2020.m` 的 quarter-car 模型中，簧上加速度行包含 `-1/m1 * u`，即正 `u` 对簧上质量为向下作用；静态平路下有 `0 = -k1*x3/m1 - u/m1`，因此正 `u` 会使 `x3 = susp_defl` 变负，和力脉冲试验的 `Jnc` 方向一致。
- 但 `src/CarSim_IO_配置清单.md` 记录的 Simulink 链路为 `per_corner_mpc -> Saturation -> Gain(-1) -> Unit Delay -> CarSim Import`。若当前模型仍按此连接，则 `per_corner_mpc` 输出的正值会在进入 CarSim 前变成负 `IMP_FS`。因此“训练脚本方向正确”不等于“在线闭环方向正确”。

未闭合点：

- 还没有“单角力脉冲试验”直接证明 `FsExt_L1/L2/R1/R2` 在 CarSim 内部作用到了正确车角。
- 必须确认当前 `u_prev` 反馈信号取自 `Gain(-1)` 前还是后。若 `u_prev` 取自 gain 后的实际 `IMP_FS`，补偿时不能简单用现有 `output_scale=-1` 同时翻转 `u_prev_model` 和 `u_cmd`；更干净的方式是移除 Simulink 的 `Gain=-1`，或者在 wrapper 中只对最终输出翻转、保持模型内部 `u_prev` 为实际 `IMP_FS` 符号。
- 当前正力方向已经验证，但 `energy_gate` 中 `u * vel_body` 的物理含义仍依赖最终送入 CarSim 的力符号和 `vel_body/Vz_SM` 的正方向定义；因此 `UV_POS/UV_NEG` 结果在确认 gain 层级前不宜解释成严格耗能/注能。

后续应补一个 `ForcePulseInterfaceCheck_2020` 工况：平路、低速或静止、每次只对一个角注入 `+500 N` 与 `-500 N` 短脉冲，记录 `Jnc_*`, `Fz_*`, `Pitch`, `Roll` 的符号响应。

### 3.3 静态平衡与基础稳定性

从 `Output/nonlinear/T2-50mm-passive/2026-06-11_15.14.34.csv` 的 `1-3 s` 平路窗口复算：

| 轮位 | 平均 `Fz` |
|---|---:|
| `Fz_L1` | `5390.16 N` |
| `Fz_R1` | `5400.19 N` |
| `Fz_L2` | `3988.88 N` |
| `Fz_R2` | `3978.72 N` |
| 四轮合计 | `18757.95 N` |
| 等效总质量 | `1912.13 kg` |

结论：

- 左右轮载接近对称，前后轴载分配稳定。
- 四轮法向载荷总和量级合理，可作为整车静态平衡的初步证据。
- 但 `Fz` 是轮胎法向载荷，不等价于“簧上质量重量”。若报告要严格写“簧上质量闭合”，必须导出 CarSim 车辆总质量、簧上质量、非簧质量和静态轴荷参数。

平路稳定性证据：

- `Output/CaseB2/flat_pose_report_compare_B2.md` 中零力/平路最终窗口 `Az_SM` 接近零，`Zgnd_*` 接近零，车轮转角连续增加，说明被动模型无明显无故自激。
- 2026-06-11 nonlinear front-only UV_POS 结果显示平路段主动悬架仍有约 `80-90 N RMS` 的微小输出，这解释了为什么全程 RMS 容易被 active 小力积累污染。

因此，后续评价应同时保留：

- 论文一致的 full-run 或 fixed-window RMS；
- 事件窗口 RMS；
- 平路段 force RMS 和 acceleration RMS，作为“主动系统是否在无路面激励下扰动系统”的补充诊断。

## 4. 尚未覆盖的高优先级验证计划

### 4.1 单角力脉冲接口试验

目的：闭环证明通道顺序和力方向。

步骤：

1. 平路、低速或静止车辆，关闭道路扰动。
2. 只对 `L1` 注入 `+500 N` 脉冲，再注入 `-500 N` 脉冲。
3. 对 `R1/L2/R2` 重复。
4. 输出 `FsExt_*`, `Jnc_*`, `JncR_*`, `Fz_*`, `Pitch`, `Roll`。
5. 判据：目标角响应最大，非目标角只出现合理耦合；正负力响应符号相反且符合 CarSim 定义。

### 4.2 当前 nonlinear rear-only 平路稳定性

目的：确认即将开始的 rear 调试不会在平路自激。

步骤：

1. 激活 `ROAD3_NONLINEAR_REAR300_ONLY`。
2. 使用 `use_nonlinear_suspension_path_2020` 确认 path。
3. 平路跑 15 s，输出完整四角 force、jounce、body acceleration。
4. 判据：`FJSt/FRSt=0`，无持续 15-20 Hz 振荡；平路 `FsExt` RMS 应显著小于事件窗口 RMS，或能被 deadband/gate 合理解释。

### 4.3 质量与静态平衡闭合

目的：把当前“轮胎载荷量级合理”升级为严格静态验证。

需要导出或记录：

- CarSim vehicle total mass；
- sprung mass；
- unsprung mass；
- static axle load；
- CG 到前后轴距离；
- 初始 `Fz_*`。

判据：

- 四轮 `Fz` 合计约等于整车重量；
- 前后轴载与 CG 分布一致；
- 若要验证簧上质量，需扣除非簧质量或使用 CarSim 的簧上载荷变量。

### 4.4 在线状态向量与 region 调度审计

目的：确认预测模型变量传递和非线性 region 选择在仿真中正确。

建议新增诊断输出：

- 当前 axle region id；
- `Jnc`, `JncR`, body velocity/acceleration 等进入控制器的 state vector；
- QP 输出未限幅值、限幅后值、gate 后值。

判据：

- region id 与 `JncR` 符号和速度范围一致；
- hysteresis 附近无高频来回切换；
- 控制输出在限幅、rate limit、energy gate 后变化符合预期。

### 4.5 T2 150 mm full 递进验证

目的：避免再次把 pilot 结论直接外推到跳车工况。

顺序：

1. 新长行程车辆 + passive T2 150 mm；
2. nonlinear rear-only 小限幅；
3. nonlinear front-only 小限幅；
4. front/rear both 低限幅；
5. 仅当 `Fz<=0` 比例、`FJSt/FRSt`、`Jnc/JncR` 均安全，再评价舒适性。

判据：

- `Fz<=0` 时间比例不得高于 passive；
- `FJSt/FRSt` 不应出现几十 kN 级止块力；
- active 不得用更差的轮胎接地或止块冲击换取 RMS 指标。

## 5. 报告结论

目前最稳妥的表述是：

> 已完成 Road-3 仿真链路的基础有效性验证：路面输入、动态预瞄、前后轴延迟、平路稳定性、离线 QP/Gurobi 求解、regionless 主动集、非线性控制律资产管理均有可追溯记录。  
> 但接口通道/符号、簧上质量静态闭合、在线状态向量传递、region 调度行为仍属于部分验证，需要用单角力脉冲、质量参数导出和在线诊断变量补齐。  
> 在补齐这些验证前，Road-3 T2 50 mm pilot 的调参结果可以作为工程迭代依据，但不宜直接作为最终论文复现结论；T2 150 mm full 必须重新按安全递进流程验证。
