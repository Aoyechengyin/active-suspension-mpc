# Road3 ACT50 严格论文作动器执行说明

## 目的

本轮优先走严格论文复现链路：不重训 nonlinear 离线控制律，只在 Simulink 的 `IMP_FS` 前加入与离线模型一致的 `tau=0.05 s` 一阶作动器。

严格链路为：

```text
per_corner_mpc output
-> road3_bump_safe_output_2020 limit/rate/gate
-> ACT50 first-order actuator
-> CarSim IMP_FS
```

严格链路中不保留外部 `Gain=-1`。`per_corner_mpc` 的 `u_prev` 输入必须来自 ACT50 实际输出 `u_act` 的上一拍，而不是 MPC 原始命令。

## 新增模式

在 `src_2020/empc_calibration_settings_2020.m` 中新增：

- `ROAD3_NONLINEAR_FRONT500_ACT50_ONLY`
- `ROAD3_NONLINEAR_FRONT500_ACT50_UV_POS`
- `ROAD3_NONLINEAR_FRONT500_ACT50_UV_NEG`

三者均为前轴 `500 N`、后轴 `0 N`，前轴 rate limit 保持 `15000 N/s`。ACT50 模式下 `smooth_tau_s=0`，避免软件平滑与物理作动器重复叠加。

## 模式切换

当前 wrapper 通过 `empc_calibration_settings_2020.m` 的 `default_mode` 切换仿真模式。当前已默认设置为：

```matlab
default_mode = 'ROAD3_NONLINEAR_FRONT500_ACT50_ONLY';
```

第一组 `ACT50_ONLY` 可以直接运行。随后分别手动切换测试：

```matlab
default_mode = 'ROAD3_NONLINEAR_FRONT500_ACT50_UV_POS';
default_mode = 'ROAD3_NONLINEAR_FRONT500_ACT50_UV_NEG';
```

每次切换后必须清 persistent。

## 验证重点

1. 单角 `+500 N` 常值命令：CarSim `FsExt_*` 为正，`Jnc` 方向符合已验证的 `IMP_FS` 正方向。
2. ACT50 阶跃：`10 ms ~= 18%`，`20 ms ~= 33%`，`50 ms ~= 63%`。
3. 输出一致性：`u_act` 与 CarSim 导出的 `FsExt_*` 应一致。
4. T2 50 mm pilot 优先跑：
   - Passive 复核
   - `ROAD3_NONLINEAR_FRONT500_ACT50_ONLY`
   - `ROAD3_NONLINEAR_FRONT500_ACT50_UV_POS`
   - `ROAD3_NONLINEAR_FRONT500_ACT50_UV_NEG`
5. 若凸包与正弦路面都明显滞后且劣于 Passive，则停止 ACT50 调参，进入 `tau=0.005/0.001` 快作动器离线重训方案。
