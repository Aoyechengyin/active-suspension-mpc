# CarSim 2020 eMPC 后续道路实验执行方案

生成日期：2026-06-06

## 1. 当前冻结基线

当前平路 MPC 基线采用：

- 基准 CSV：`Output/CaseB4/2026-06-06_00.28.33.csv`
- 基准报告：`Output/CaseB4/flat_pose_report_compare_B4_real.md`
- 控制器参数：
  - `rho5_front = 1e-7`
  - `rho5_rear = 1e-4`
  - 前轴限幅：`3000 N`
  - 后轴限幅：`2000 N`
- CarSim Import 顺序固定为：`[IMP_FS_L1, IMP_FS_L2, IMP_FS_R1, IMP_FS_R2]`
- Simulink Mux 顺序固定为：`[L1, L2, R1, R2]`
- 当前默认控制模式：`B3_CONSERVATIVE`

后续道路实验开始前，不再修改车辆参数、悬架参数、Simulink 接口顺序、力方向和求解器设置。

## 2. 之前校准过程留痕

平路姿态校正过程的关键判断如下：

- CaseA 零力平路正常，可作为被动车辆基准。
- 原始全 MPC 异常集中在后轴：后轴外力长期触及 `±9000 N`，并引发明显垂向冲击和左右反向力。
- CaseB1 前轴 MPC、后轴零力后，垂向暴力现象消失，说明后轴控制是主因。
- CaseB2 后轴低限幅且保持原力方向时可以稳定运行。
- CaseB2-rev 后轴反向后出现更明显振荡，因此后轴力方向不反。
- CaseB3 前轴 `3000 N`、后轴 `2000 N` 后姿态变好，但后轴仍有明显限幅。
- CaseB4 重新生成 rear QP，并将 `rho5_rear` 提高到 `1e-4` 后，平路 MPC 达到当前可接受状态：
  - `Roll mean ≈ 0.002 deg`
  - `Az_SM peak ≈ 0.0043 g`
  - 后轴 `JncR peak ≈ 1.33 mm/s`
  - 四角 `FsExt` 无饱和
  - 后轴左右外力差峰值约 `3.4 N`

这个过程说明：后续道路实验必须先守住 B4 基线，不能直接恢复复杂 3D Road 或论文随机路面。

## 3. 实验升级顺序

### Road-0：平直 3D Road

目的：验证启用 3D Road 和 VS preview export 后，平路基线没有被破坏。

设置：

- Road 使用平直 3D Road。
- 保持 `W1/W2` VS Command 动态预瞄导出。
- 保持直线 `50 km/h`。
- 保持 Steering 为 `0 deg`，不要恢复 DLC 或 Driver Path Follower。

验收：

- `max(abs(Zgnd_*)) < 1e-6 m`
- `W1_*`、`W2_*` 与 `Zgnd_*` 均应为平路。
- 姿态、`Az_SM`、`FsExt_*` 接近 B4 基线。

### Road-1：极小幅可控路面

目的：只验证预瞄时间关系，不考验控制性能。

设置：

- 路面幅值先用 `1-2 mm` 量级。
- 优先使用低频、平滑、可重复路面。
- 保持当前 MPC conservative 设置。

验收：

- `W1` 相对当前轮下 `Zgnd` 提前约 `10 ms`。
- `W2` 相对当前轮下 `Zgnd` 提前约 `20 ms`。
- 若 CSV 采样间隔大于 `10 ms`，以分析报告中的 estimated lead 作为参考，不只凭肉眼判断。

### Road-2：低幅单凸包

目的：确认车辆在小扰动下不会重新出现后轴限幅振荡。

设置：

- 第一次凸包高度：`5 mm`
- 第二次凸包高度：`10 mm`
- 其余条件保持 Road-1 不变。

验收：

- 四角 `FsExt_*` 配置限幅饱和比例 `< 1%`
- 不出现持续 `15-20 Hz` 振荡。
- `Rot_*` 连续增加。
- `Az_SM`、`JncR_*` 有短时响应，但不能长时间不衰减。

### Road-3：论文凸包工况

目的：恢复论文中规则凸包或速度凸包工况。

执行细则已经单独整理到：

```text
日志/Road3论文凸包实验执行说明_20260606.md
```

设置：

- 执行前必须重新核对论文中的具体路面参数，并记录在本文件或单独实验记录中。
- 同一条路面至少跑三组：
  - Passive/零外力
  - eMPC no-preview：所有 preview road states 等同当前 `road_now`
  - eMPC preview：使用动态 `W1/W2`

验收：

- preview 组不应出现长期限幅。
- no-preview 与 preview 的差异应体现在 `Az_SM` 峰值/RMS、悬架动挠度和控制力 RMS 上。
- 若结果与论文趋势相反，先检查 `W1/W2` 对齐和力饱和，不先改权重。

### Road-4：论文随机路面

目的：恢复论文随机路面，并计算 RMS、PSD、频率加权指标。

设置：

- 先用较低粗糙度或较小尺度版本跑通。
- 再恢复论文完整随机路面。
- 仍然跑 Passive、no-preview、preview 三组。

验收：

- 计算 `Az_SM*9.81` 的 RMS。
- 计算 `Jnc_*`、`JncR_*`、`FsExt_*` 的 RMS 和峰值。
- 对 `Az_SM` 或车身垂向响应做 PSD，观察主频是否合理。
- 若 `15-20 Hz` 限幅振荡重新出现，停止升级路面并回退到 Road-2。

## 5. 分析命令

单个道路实验：

```matlab
addpath('src_2020');
AnalyzeRoadExperiment_2020( ...
    'Output/Road0/your_result.csv', ...
    'Output/Road0/road_experiment_report.md');
```

与 B4 基线对比：

```matlab
addpath('src_2020');
AnalyzeRoadExperiment_2020({ ...
    'Output/CaseB4/2026-06-06_00.28.33.csv', ...
    'Output/Road0/your_result.csv' ...
}, 'Output/Road0/road_experiment_report_compare.md');
```

脚本会输出：

- 路面事件窗口。
- `Zgnd/W1/W2` 预瞄 lead 估计。
- `Az_SM` 峰值和 RMS。
- `JncR_*` 峰值。
- `FsExt_*` 峰值、RMS、配置限幅饱和比例、硬 `9000 N` 饱和比例。
- 前后轴左右外力差。
- `Roll/Yaw/Yo` 最终姿态。
- `Rot_*` 全程增量。

## 7. 出错处理规则

- 如果修改 Road 后 CarSim 不能运行，先断开 MATLAB/Simulink，单独运行 CarSim 的 `Run the Math`。
- 优先检查 CarSim Results 运行文件夹，不先改控制器。
- 如果 Road-0 都不能通过，说明问题在 CarSim road/VS Command/I/O，不在 eMPC。
- 如果 Road-0 正常、Road-1 预瞄不对，优先查 `W1/W2` VS Command 和 Export 顺序。
- 如果 Road-1 正常、Road-2 出现振荡，优先查 `FsExt` 饱和、后轴左右差和 `15-20 Hz` 主频。
