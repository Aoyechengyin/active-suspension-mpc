# 平路车身姿态校准执行说明

> 日期：2026-06-04  
> 目的：先确认平路直线下车身姿态、四轮悬架力和左右对称性，再逐步恢复 3D Road 与论文路面工况。

## 1. 工况设置

### Case A：平路直线零力模式

- CarSim 工况使用平直路面，不使用 DLC / Double Lane Change。
- Steering 固定为 `0 deg`，不要使用 `Driver Path Follower`。
- 车速先保持 `50 km/h`。
- Simulink 四路 Import 全部送 `0 N`。
- StopTime 使用 `15 s`。

验收重点：

- `Roll` 是否自然稳定。
- `Pitch` 是否稳定在一个小的常值。
- `Yaw` 和 `Yo` 是否接近 0。
- 四轮 `Jnc_*` 左右是否基本对称。

### Case B：平路直线 MPC 模式

- 保持 Case A 的 CarSim 工况不变。
- 使用当前 e-MPC 控制链路。
- Simulink 到 CarSim 的 Mux / Import 顺序保持当前跑通顺序。
- 当前模型内部 Mux 逻辑顺序为：

```text
L1, L2, R1, R2
```

验收重点：

- `Fs_L1` 与 `Fs_R1` 是否接近。
- `Fs_L2` 与 `Fs_R2` 是否接近。
- `Roll` 不应持续漂移。
- `Yaw` 和 `Yo` 不应比 Case A 明显恶化。

## 2. CSV 必要诊断变量

后续 CSV 分析按列名读取，不强制列顺序。建议导出以下列：

```text

Pitch

Yaw
Xo

Fs_L1
Fs_R1
Fs_L2

Jnc_L1
Jnc_R1
Jnc_L2
Jnc_R2

JncR_R1
JncR_L2
JncR_R2
Zgnd_L1
Zgnd_R1
Zgnd_L2
Zgnd_R2
```

说明：

- `Fs_*` 使用 CarSim Export 的实际四轮悬架力，单位按 CarSim 输出设置保持为 `N`。
- `Ay_SM` 必须增加，用来判断侧倾是否由横向加速度激发。
- `Jnc_*` 和 `JncR_*` 用于判断左右悬架响应是否对称。
- `Zgnd_*` 用于确认平路阶段左右路面高度是否一致，后续恢复 3D Road 时也用于排查路面问题。

## 3. 分析脚本

单个 CSV：

```matlab
addpath('src_2020');
AnalyzeFlatPose_2020('Output/LastRun_flat_zero.csv');
```

零力与 MPC 对比：

```matlab
addpath('src_2020');
AnalyzeFlatPose_2020({ ...
    'Output/LastRun_flat_zero.csv', ...
    'Output/LastRun_flat_mpc.csv' ...
});
```

脚本会生成 Markdown 报告，例如：

```text
Output/flat_pose_report_LastRun_flat_zero.md
Output/flat_pose_report_compare.md
```

## 4. 判据

平路直线建议先按以下口径判断：

- `Final 2 s |Roll_mean| < 0.05 deg`
- `Final 2 s Roll_peak_abs < 0.2 deg`
- `Final 2 s Yaw_peak_abs < 0.2 deg`
- `Yo` 全程漂移小于 `0.05 m`
- `Fs_L1 - Fs_R1` 的 Final 2 s 均值绝对值小于 `100 N`
- `Fs_L2 - Fs_R2` 的 Final 2 s 均值绝对值小于 `100 N`

如果 Case A 已经不满足，优先查 CarSim 车辆、平路、转向和初始条件。  
如果 Case A 正常但 Case B 异常，再查 e-MPC 力方向、Import 顺序、Jounce 单位和控制器状态估计。

## 5. 进入 3D Road 前的规则

平路姿态通过前，不恢复论文路面。恢复时按以下顺序：

1. 平直 3D Road，所有高度为 0。
2. 平直 3D Road + 当前 VS Command 预瞄输出，确认 `Zgnd/W1/W2` 没有破坏仿真。
3. 单个低幅值凸起。
4. 论文目标路面。

每一步只改一个因素，避免再次出现“改路面后无法判断是哪一层出错”的情况。
